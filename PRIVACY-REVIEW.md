# Tempo Squarespace pages

Paste each HTML file in full into its own Squarespace HTML Code Block, with Display Source disabled. These are fragments, not standalone HTML documents. Set page slugs to /privacy and /support. Keep both public and add footer links. No scripts, external fonts, or additional tracking are included.

## Privacy draft: confirm before publishing

This draft reflects a source-code review, not a verification of production operations. Confirm:

- The legal operator/business name and appropriate contact details. The draft uses the Tempo brand and the supplied email; add the operator identity where appropriate.
- Actual hosting, database and email providers, processing locations, international transfers, and contractual safeguards.
- Exact retention/deletion behavior for forum content, direct messages, game chats, media, analytics, logs and backups. The deletion route explicitly removes the user and refresh tokens and attempts profile/banner asset cleanup; cascading data deletion and other asset cleanup need verification. Replace the general retention section with confirmed periods or criteria and residual-data behavior.
- Whether any personal information is sold, shared for advertising, used for tracking, or disclosed beyond the services described. The draft intentionally makes no unverified no-sale/no-tracking claim.
- Intended minimum age and child-data practices. The draft does not invent an age restriction.
- Region-specific rights, legal bases, retention obligations and disclosures applicable to the operator and users.
- Website cookie/analytics behavior: this policy covers the app and support, not a completed audit of Squarespace cookies or website forms.
- That the supplied mailbox receives mail and is monitored, and that report handling matches the public support instructions.

Use the actual publication date if different from the draft date. Match App Store privacy answers to confirmed production behavior. Support HTML is ready for content review; privacy HTML remains a draft until these facts are confirmed.

## Verify after pasting

Visit both pages signed out on mobile and desktop. Check heading hierarchy in the full Squarespace page (avoid duplicate page H1 titles), email links, keyboard focus, text wrapping, and cross-links. Squarespace's surrounding theme can affect rendering.
